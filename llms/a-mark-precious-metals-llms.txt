# A-Mark Precious Metals

> A-Mark Precious Metals, Inc. is a full-service wholesale precious-metals trading company
> that sells gold, silver, platinum and palladium bullion and coins to dealers, financial
> institutions and investors, and also runs logistics/storage, custom minting and
> collateralized lending. A-Mark is renaming to Gold.com, Inc. and transferring to the NYSE
> under the ticker GOLD; it now sits as one brand inside the Gold.com brand family.

Generated by the API Evangelist enrichment pipeline on 2026-08-29 from apis.yml and the
artifacts in this repository. A-Mark does not serve an llms.txt of its own — /llms.txt
returns 404 on www.amark.com, amark.com and www.gold.com.

## What an agent should know first

A-Mark publishes NO public developer program: no developer portal, no API reference, no
OpenAPI or GraphQL or SOAP contract, no SDK, no CLI, no MCP server, and no agent card.
Access to the trading surface runs through the A-Mark Trading Portal, and credentials are
issued through dealer onboarding (newaccounts@amark.com, trading@amark.com), not
self-service signup. An agent cannot call A-Mark today without an existing dealer
relationship.

## Machine-readable surfaces actually served

- [OpenID/OAuth discovery](https://portal.amark.com/.well-known/openid-configuration): the ONLY machine-readable contract A-Mark serves. OAuth 2.0 password + refresh_token grants, token endpoint https://portal.amark.com/connect/token.
- [JWKS](https://portal.amark.com/.well-known/jwks): served but empty — {"keys":[]}.
- [WordPress REST index](https://www.amark.com/wp-json/): 738 routes, all stock WordPress/WooCommerce/plugin namespaces. Platform default behaviour, NOT an A-Mark product API. A-Mark neither documents nor supports it; do not treat it as a supported integration surface.
